# RemindCare

RemindCare adalah aplikasi mobile yang dirancang untuk membantu lansia dan pendamping keluarga dalam mengelola jadwal minum obat secara teratur. Aplikasi ini menyediakan fitur pengingat otomatis, manajemen data obat, pemantauan kepatuhan konsumsi obat, serta sistem autentikasi yang aman untuk mendukung pengelolaan kesehatan sehari-hari.

## Features

* User Authentication (Login & Register)
* Medication Management (CRUD Obat)
* Medication Schedule Reminder
* Push Notification Reminder
* Medication Adherence Monitoring
* Family Caregiver Support
* REST API Backend (PHP Native OOP)
* Flutter Mobile Application

## Technology Stack

* Flutter
* PHP Native OOP
* MySQL
* JWT Authentication
* RESTful API
